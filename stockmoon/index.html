Returns & moments

Prices are adjusted for splits and dividends by Yahoo Finance. Daily returns compare consecutive sessions; weekly returns compare closes five trading sessions apart. Snapshot moments describe the equal-weight distribution across stocks, not the capitalization-weighted S&P 500 index. SPY is shown separately as a benchmark.

Standard deviation and variance use the sample correction. Skewness is bias-corrected Fisher–Pearson; kurtosis is bias-corrected Fisher excess kurtosis. History charts default to exponential smoothing with a four-week half-life, using elapsed calendar time so weekly and daily observations are treated consistently. Smoothing uses only past data; raw readings remain available on hover. Snapshot cards, distributions, stock tables and data files are unsmoothed. The stock table shows moments over each stock's rolling history. A verified unadjusted corporate-action discontinuity is excluded only from returns crossing the event; affected stocks also leave the complete-history correlation panel. These exceptions are listed in the report. Generic outliers are retained.

Correlation & components

Daily analysis uses 252 sessions. Weekly analysis uses 104 completed Friday-ending weeks, with the last session of holiday weeks as the close. Only stocks with complete, nonconstant histories enter each correlation matrix. Missing observations are never filled.

We take the SVD of the Pearson correlation matrix. Each variance share is its singular value divided by their sum. Representatives rank by absolute loading: eigenvector weight × square root of eigenvalue. Component ranks and signs can change across dates; these are statistical directions, not fixed portfolios.

The historical blind spots

Weekly snapshots begin in 1997 using community historical membership lists. Yahoo often lacks delisted stocks; early samples are incomplete and have selection bias. Symbol reuse and corporate lineage are not independently verified. Older company names and sectors may be unclassified. After the last archived membership event, the current list is used.

Read each date's coverage before making comparisons. A complete, unbiased historical S&P 500 reconstruction requires a survivorship-free price database and a security master.
